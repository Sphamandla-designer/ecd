Figma file: `8s2xe3EyBRhrzDFy93NbfN` · Canvas node: `145:23196` · Canvas name: **"Page 24"**

## Page overview

This page contains the complete **Child Progress** feature of the ECD Connect mobile app (360x640 baseline frames), spanning the `WO5.x` screen family plus supporting `0.3.0` dashboard states, `1.2.7` reporting-period setup, `4.2.x`/`4.3.x` "Themba" example flows, and `5A.6`/`WO5.4` walkthroughs. It covers:

- **Progress reporting-period setup** (principal-only yearly configuration; error dialogs for invalid date ranges).
- **Progress landing pages** per child (empty / in-progress / with previous reports; over-age states).
- **First progress observations flow** (age-banded questionnaires, CREDI/NCF/ChildSteps-based, 5 questions per screen, Yes / No / Don't know answers, reverse-scored items, "choose 4 skills to work on" step, completion summary grouped by developmental category).
- **Create caregiver report** (3-step form, irreversible-create warning dialog, view completed report).
- **Share report** (language selection, sharing tips, share steps).
- **Progress tab dashboard** (report-completion %, download all reports, "See summary" filters by class/age, category vs individual-child summary views).
- **Progress walkthrough** (12-step tutorial with mascot dialog cards, language picker dialog).
- **Info page, hub/system notifications, and the printable Progress Summary PDF (A4, 2480x3508).**
