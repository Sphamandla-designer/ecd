## 1. Page overview

Page 23 is the design spec for the **DBE Registration Helper** — the in-app flow that walks an ECD
(Early Childhood Development) preschool principal through registering their programme with the South
African **Department of Basic Education (DBE)**, so they can qualify for the ECD subsidy.

The page is organised into **7 numbered, "Approved"-stamped sections**, each introduced by a wide
black `Header` banner instance spanning the full canvas width (3568 px, 300 px tall; heading text at
x=120, y=77, 146 px tall; green "Approved" status pill to the right of the heading).

All phone screens are drawn at the standard **360 × 640** mobile artboard (some taller where the
content scrolls: 706 / 750 / 942 / 952 / 1035 / 1066 / 1076 px).

The underlying domain model is a two-stage DBE registration ladder:

* **Apply → Bronze certificate**
* **Comply → Silver certificate**

Both stages are surfaced on the Money-tab dashboard as a vertical stepper with per-stage "View"
buttons, and each stage has a dedicated long-form info screen (`WO7.5.0 General info page`).
